## 1. 목표

폐루프에서 **움직이는 보행자가 경로에 들어오면 제동을 시작하는 모델**을 얻는다. 차선 추종(R2 ft 수준)은 지킨다. 그 뒤의 일(가중치 보간, 로타리, 미리 줄이기)은 이 능력이 생긴 다음이다.

## 3. 이번 설계가 겨냥하는 것

| 실패 원인 | 조치 | 상태 |
|---|---|---|
| nav_text 지름길 | 돌출 전처리 v2: path_s로 nav_text·cell 재계산, 기본값 제거 | popout-rebuild 세션, B2 `step0_popout/_dyn_relabel_v2/` |
| 이력 지름길 | 정지·적신호 행 이력 실제·0·합성 1/3(B). replay 전체 드롭아웃(교사 행 실제/0 반반, 적신호 행 B). 돌출 정지 행은 드라이버가 안 서서 이력이 순항(감속 단서 0.2 %, 확인) | 설정 반영 |
| 장소·가림물 지름길 ("주차차/이 장면 → 제동") | **새 소스 `popout_cruise` 5 %**: 같은 돌출 에피소드의 onset 0.5 s 전까지 원본 행(서 있는 보행자, 주차차) = 순항 라벨. 사건 없는 에피소드 전부 | 이번에 추가 |
| 모순 입력 | 돌출 재출발 행 제외(v2에서 생성 안 함) | 결정 |
| 라벨-입력 불일치(보이기 전 제동) | 원래 LiDAR 기준 유지(LiDAR 광선 보임 + 움직임 + 충돌 경로). 카메라 30 px 필터는 결정 행(첫 0.1–0.3 s)을 빼서 제동이 약 3 m 늦어지므로 안 씀. 모델은 LiDAR BEV도 입력 | 사용자 결정 |
| 결정 순간 학습 부족 | onset 뒤 1.0 s 행 ×4(소스 안 정규화). 가까운 갓길 사건(26개, 라벨 시작 시 100 % 보임)은 ≈8회 반복 | 설정 반영 |
| 차선 망각 | R2 ft 시작 + R2 ft 고정 교사로 유지 행(차선·곡선·정적·적신호 아닌 replay) 속도장 증류(vkd 1.0) + GT. 정지·적신호 행은 GT만 | 설정 반영, 테스트 통과 |
| 양자화에서 새 능력 손실 | QAD 교사 = LwF ft final 자신, 모든 행 vkd + GT (정석 QAD) | 설정 반영 |
| 오프라인에서 못 알아챔 | FtSelect 기록 세트: **제동 시작률**(돌출 val onset 행에서 1 s 안 1.5 m/s 이상 감속) / **onset 대조**(onset −1.5~−0.5 s 행의 오제동률) / 정적·일반 오제동률. step 0과 500마다 | 3번 세션 구현 중 |

## 6. 실행 절차

1. 게이트: `tools/vast/rent_gate.sh`(B2 파일 수, 로더 검사 로그, 세 클라우드 표). 이번에는 원본이 B2에 있고 전처리가 상자에서 끝나도 되므로, 로더 검사는 pre-rebuild 로그 + 상자에서 ft 직전 재검사.
2. 상자: 8×H100(Brev hyperstack $25/h, 252 vCPU 1순위; OCI 112 vCPU 2순위). vast 8×H200은 $76/h라 제외. Brev create는 사용자 로그인 필요.
3. 다운로드 중(GPU 유휴 시간): gpu_check, 실제 설정 50 step, LwF 5분 스모크(교사 메모리), **dynbal nav_text 프로브**(§7), 전처리 v2(필요 시), `lwf_mix` → `dyn_stage` → `dyn_load_check`.

5. 감시: 3번 세션이 2분 주기 직접(`r2ft_autowatch.py`). 보고 양식 `HH:MM | 단계 step/총 s/step | $/h·지출·잔액 | 제동 onset/pre | ETA`.

## 7. 판정과 비상 계획

- **dynbal nav_text 프로브**(상자 GPU 0, 다운로드 중, 최선 노력): dynbal ft final에 v2 돌출 val onset 행을 (a) 버그 문구 (b) 고친 문구로 넣어 3 s 계획 속도와 제동 시작률을 비교. (a)에서만 밟으면 §2 ①이 확인된다. 결과 B2 `runs/lwf/<RUN>/navprobe/`.
- **학습 중**: step 1000에서 onset 제동 시작률이 step 0 대비 +10 pp 미만이면 즉시 보고(자동 중지 없음). 공격 변형 override 준비: 돌출 35 %, 결정 행 ×8, replay 15 %, `model.init=checkpoint-1000`로 1,000 step 추가. 실행은 사용자 결정.
- **onset 대조**: onset 행과 pre_onset 행의 제동률이 둘 다 높으면 장소 지름길, 둘 다 낮으면 인식 실패, onset만 높으면 의도대로.
- **폐루프**(납품 뒤, 사용자): 동적 충돌 수, 계획 궤적이 보행자 등장 뒤 짧아지는지(인식) / 짧아졌는데 박는지(지연) / 안 짧아지는지(인식 실패). 차선 위반 수는 dynbal과 비교.
