# 와우마요 개발기 목차 (내용 순서)

연재는 시간순이 아니라 개발 내용의 진척 순서로 나눈다. 각 편은 논문의 한 장처럼 하나의 질문에 답한다.
원문은 `_old/ep0N.md`(시간순 초고)이고, 아래 "원문" 칸은 그 파일의 절 제목이다.

| 편 | 제목 | 이 편이 답하는 질문 |
|---|---|---|
| 1 | 문제 정의 편 | 무엇을, 왜 증류하는가. 원본 Alpamayo는 MORAI에서 얼마나 못하는가. 무엇으로 평가하는가 |
| 2 | 데이터 편 | 어떤 데이터와 어떤 정답으로 가르치는가 |
| 3 | 모델 설계 편 | 교사와 학생을 어떻게 짜고, 무엇을 증류하는가 |
| 4 | 교사 적응 편 | 교사를 MORAI에 어떻게 적응시켰고, 어떤 지표로 골랐는가 |
| 5 | 학생 증류와 경량화 편 | 학생을 어떻게 배웠고, 5080 10 Hz에 어떻게 올렸는가 |
| 6 | 폐루프 평가 편 | 실제로 달리면 어디서, 왜 실패하는가 |
| 7 | 데이터 보강과 미세조정 편 | 실패의 원인이 된 데이터 결손을 어떻게 메웠고 무엇이 바뀌었는가 |
| 8 | 정지 능력 편 | 동적 장애물 앞에서 서는 법을 왜 못 배웠고, 무엇을 고쳤는가 |
| 9 | 결과와 고찰 편 | 버전별로 무엇이 효과가 있었고, 무엇이 남았는가 |
