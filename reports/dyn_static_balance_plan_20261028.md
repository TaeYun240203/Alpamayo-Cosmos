# 와우마요 동적·정적 균형 학습 계획 (2026-10-28)

이번 학습은 R2 ft 최종에서 다시 시작합니다. 목표는 차선 추종을 지키면서 동적 장애물 앞에서는 서고, 정적 장애물은 피하게 하는 것입니다. 합성 라벨과 replay 정제의 상세 판정식·그림은 [dyn_relabel_20261028.md](dyn_relabel_20261028.md)에 있습니다.

## 1. 목적과 배경

| 모델 | 좋아진 것 | 나빠진 것 |
|---|---|---|
| R2 ft (오늘 아침 납품) | 차선 추종(차선 위반 바퀴당 16–25회), 8바퀴 중 6바퀴 완주 | 신호 위반 8바퀴 중 3번, 동적 장애물을 늦게 감속, 로터리 진입 대기 |
| 정지 보강 (13:08 납품) | 신호 위반 0회(3바퀴), 적신호 검증 ADE 4.54 → 2.35 | 차선 위반 38–54회, 정적 장애물 19 m 앞에서 정지, 곡선 횡오차 0.54 → 0.98 m |

- 정지 보강이 나빠진 원인은 데이터 구성입니다.
  - 차선·곡선 행이 25 %에서 10 %로 줄었습니다.
  - R2 일반 주행이 45 %에서 0 %로 줄었습니다.
  - 서는 행이 50 %였습니다.
- 서 있는 물체가 정적 소품인지, 곧 움직일 물체인지는 겉모습으로 구분되지 않습니다. 정지 데이터만 늘리자 모델이 "서 있으면 선다" 쪽으로 기울었습니다.
- R2 동적 정답에는 두 가지 문제가 있었습니다.
  - 82 %가 원인이 보이기 전부터 서는 행입니다.
  - 드라이버의 AEB는 마지막 순간에 밟습니다.

  그래서 동적 정답을 합성 라벨로 바꿉니다.

## 2. 시작점과 학습 설정

| 항목 | 값 |
|---|---|
| 시작점 | R2 ft 최종 BF16 (B2 `runs/r2ft/ft/final`). 정지 보강 ft 최종은 쓰지 않음 |
| 길이 | 1,000 step = 32,000 샘플 (1 % = 320 샘플) |
| 학습률 | 최고 1e-6, 워밍업 50 step, cosine으로 3e-7까지 |
| 층별 배율 | 카메라 ViT 0.1, expert·action in/out 0.3, LiDAR ViT·LLM 1.0 |
| 손실 | 하드 타깃만: fm 1, 궤적 CE 1, lm 1. T* 없음 |
| 기본 이력 드롭아웃 | R2 ft와 같이 정답 행의 50 %에서 이력을 0(제자리)으로. 정지·감속 행은 0 대신 합성 이력(속도는 실제) |
| 검증 세트 | general 1,000 / 적신호 300 / 동적 정지 합성 val(동적 구간 + 터널) / 곡선 600 |
| 중단 스위치 | general_wo_relabel 횡오차가 시작점의 2배를 2번 연속 넘으면 멈춤 |
| 최종 선택 | 마지막 체크포인트 |
| QAD | 같은 혼합, 800 step, 학습률 1e-6 (`student_qad_dyn.yaml`) |

## 4. 합성 라벨 규칙

물체가 보이고 경로에 들어오는 첫 프레임부터 남은 거리에 맞게 제동합니다. 모자라면 최대 6.96 m/s²까지 씁니다.

| 항목 | 정의 |
|---|---|
| 대상 | 사람과 이동 소품(자전거·스쿠터·유모차 등). 차량과 서 있는 정적 물체는 뺌 |
| 물체 궤적 | bag에 Object Info가 없어, 장면 설정(경로·속도)과 드라이버 로그(2초 간격 이동량)로 복원. 직선·등속 가정 |
| 보임 | 카메라 위치에서 50 m 안, 진행 방향 ±100° 안, 주차차에 가려지지 않음(2D 광선 검사) |
| 충돌 경로 | 물체를 현재 속도로 6.4초 예측해 자차 경로 ±1.8 m(반폭 0.95 + 여유 0.5 + 물체 0.35) 안에 들어오면 충돌 경로 |
| 필요 감속 | v² ÷ 2(남은 거리 − 정지 여유 3 m) |
| 부드러운 정지 | 필요 감속 ≤ 2.5 m/s²: 원래 주행을 유지하다 2.0 m/s² 감속을 시작해야 하는 지점부터 섬 |
| 급정거 | 필요 감속 > 2.5 m/s²: 그 프레임부터 필요한 만큼, 최대 6.96 m/s². 못 서면 최대 제동 유지 |
| a_max | R2 드라이버 AEB 정지 134건 평균 감속의 중앙값 6.96 m/s² (p90 8.76) |
| 정지 유지 | 물체가 경로 폭 안에 있는 동안 속도를 다시 올리지 않음 |
| 재출발 | 물체가 경로 폭을 벗어나고 0.5초 뒤부터 1.5 m/s²로 원래 속도까지 가속(손실 마스크 대신) |
| 반대 예시 | 보이지만 충돌 경로가 아닌 이동체 앞에서 드라이버가 브레이크를 밟지 않은 행. 라벨 = 원래 주행 |
| 전처리 | 합성 행마다 속도·방향 배열만 바꾼 가상 에피소드. 카메라·LiDAR 파일은 원래 에피소드를 가리키는 링크. 로더·손실 코드는 고치지 않음 |
| 자기 검사 | 행마다 assert: 라벨 ≤ 원래 속도, 감속 ≤ a_max, 유형 일치, 반대 예시 = 원래 주행 |

동적 구간(R2 A) 합성 결과:
- 정지 train 4,772행: 부드러운 정지 3,055 / 급정거 775 / 튀어나옴 622 / 기다림 320
- 통과 6,757행
- 가까이서 튀어나오는 예시는 R2에 거의 없습니다(급정거형 9행).
- 터널(R2 B) 합성은 만드는 중입니다.

## 6. 순서와 상자 규칙

데이터가 B2에 다 올라가고 사용자가 구성을 확정한 뒤에만 상자를 빌립니다.

1. 합성 라벨 세션이 데이터를 만들고 B2에 올립니다: 가상 에피소드, 터널 합성, 정적 회피 풀, 설정. 지금 로더로 읽는 CPU 시험을 통과해야 합니다.
2. 이 문서의 구성표를 행 수로 채우고 사용자가 확정합니다.
3. 메인 세션이 "시작"을 보내면 ft-preflight가 세 클라우드(vast·RunPod·Brev)에서 납품까지 가장 빠른 상자를 빌립니다. 총비용 상한은 $70입니다.
4. 데이터 받기, GPU 점검, ft 1,000 step 순서로 진행합니다.
5. 같은 혼합으로 QAD 800 step을 돌린 뒤 **바로 납품**합니다. 다른 업로드는 그 뒤입니다.
6. 영상 상자는 납품 약 30분 전에 켜서 데워 둡니다.
   - 납품 즉시 새 무작위 시드로 8바퀴를 돌리고, 바퀴마다 영상을 보냅니다.
   - 30초 정체 복귀 규칙을 씁니다.
7. 관문은 납품 뒤에 돌립니다. 체크포인트는 마지막에만 올리고, B2 확인 뒤 safe_destroy로 상자를 지웁니다.

## 7. 위험과 확인할 지표

가장 큰 위험은 차선 추종이 다시 무너지는 것이고, 폐루프 차선 위반 수로 판단합니다.

| 위험 | 막는 방법 | 확인 지표 |
|---|---|---|
| 차선 추종 회귀 | 차선·곡선 15 %, 합성 이력, R2 ft에서 시작 | 곡선 검증 횡오차(시작 0.54 m), 폐루프 차선 위반(R2 16–25회/바퀴) |
| 정적 장애물 앞 정지 | 정적 회피 15 %, 정적 물체 정지 창 제외 | 폐루프 s 약 325·터널 소품 앞 정체 복귀 수 |
| 동적 장애물 늦은 제동 | 보이는 순간 제동하는 합성 라벨, 급정거 30 % | 동적 물체 충돌 수, 합성 val ADE |
| 이유 없는 감속 | 동적 통과 5 %, 보이기 전 정지 제외 | 일반 구간 정체 복귀 수 |
| 적신호 위반 되돌아감 | 적신호 10 % | 신호 위반 수(R2 8바퀴 중 3번, 정지 보강 0) |
| 급정거 예시 부족 | 합성으로는 근거리 튀어나옴을 만들 수 없음 | 영상에서 튀어나옴 충돌이 보이면 녹화 또는 DAgger로 채움 |

- 동적 물체 궤적은 직선·등속으로 복원한 것이라, 보행자가 멈칫하는 시점은 2초 단위로만 맞습니다.
- 주차차 뒤 가림 판정은 2D 근사라 실제 카메라에 보이는 시점과 다를 수 있습니다.

## 8. 결정된 것과 아직 정할 것

**결정됨 (사용자 10/28)**

- 시작점은 오늘 아침 납품된 R2 ft 최종 BF16입니다.
- R2 A·B 원래 행은 이번에 만든 합성 라벨과 정적 회피 풀로 바꿉니다.
- 옛 곡선, 출발 재라벨, 끼어든 차 정지 창은 빼고, 정적 물체 때문에 선 창도 뺍니다.
- replay는 찾아낸 함정을 정제한 판을 씁니다.
- 로더 패치 없이 전처리(가상 에피소드)로 넘깁니다.
- 상자는 데이터 준비와 메인의 "시작" 뒤에만 빌립니다.
